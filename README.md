# Titanic 생존 예측 프로젝트 

> 머신러닝 기반 생존 예측 모델을 구축하고다양한 변수들이 생존에 어떤 영향을 미쳤는지 분석한 데이터 분석 프로젝트입니다.

##  프로젝트 개요

- **개발 기간:** 2025.03.15 ~ 2025.04.17  
- **개발 인원:** 개인 프로젝트  
- **사용 기술:**  
  `Python`, `Pandas`, `NumPy`, `Scikit-learn`, `Matplotlib`, `Seaborn`

##  분석 목표

1. 사회경제적 요인(Pclass, Title 등)이 생존에 끼친 영향 분석  
2. 로지스틱 회귀, 의사 결정 트리를 이용한 생존 예측 모델 구축  
3. 실무형 ML 파이프라인 구축 및 데이터 전처리 역량 강화

##  데이터 개요

- **출처:** [Kaggle Titanic Competition](https://www.kaggle.com/c/titanic)
- **구성:** 훈련 데이터 891명, 테스트 데이터 418명
- **결측치:** `Age`: 19.9%, `Cabin`: 77.1%, `Embarked`: 0.2%

### 주요 변수 예시

| 변수명 | 설명 | 예시 |
|--------|------|------|
| `Pclass` | 객실 등급 (1~3) | 3 |
| `Sex` | 성별 | male |
| `Age` | 나이 | 22 |
| `SibSp` | 형제/배우자 수 | 1 |
| `Parch` | 부모/자녀 수 | 0 |
| `Fare` | 요금 | 7.25 |
| `Embarked` | 탑승항구 | S |

## 주요 분석 결과

### 생존율 분석

- **전체 생존율**: 38.4%  
- **여성 생존율**: 74.2%, **남성 생존율**: 18.9%  
- **1등급 여성 생존율**: 97%  
- **혼자 탑승한 승객 생존율**: 30%

### 전처리 주요 항목

- `Age`: 직함(Title) 기반 평균값으로 대체  
- `Cabin`: 결측률이 높아 제거  
- `Name`에서 `Title` 파생 → `Mr`, `Mrs`, `Miss`, 등  
- `FamilySize`, `IsAlone`, `AgeBin` 등 파생 변수 생성  
- 수치형 변수 로그 변환 및 `MinMaxScaler` 적용

## 🤖 모델 성능 비교

| 모델 | Accuracy | Precision | Recall | F1 |
|------|----------|-----------|--------|----|
| 로지스틱 회귀 | 80.2% | 82.6% | 71.4% | 76.6% |
| 결정 트리 | 83.1% | 79.2% | 78.1% | 78.7% |

- **최종 모델 선택:** 결정 트리 (성능과 해석력 균형 고려)

### 변수 중요도 (결정 트리)

| 변수 | 중요도 |
|------|--------|
| Sex | 0.35 |
| Fare | 0.17 |
| Age | 0.15 |
| Pclass | 0.12 |
| Title | 0.11 |

##  성능 평가

- **5-Fold 교차 검증 평균 정확도**: 81.8% (결정 트리 기준)  
- **AUC**: 로지스틱 회귀(0.863), 결정 트리(0.845)  
- **혼동 행렬**:
  ```
  [[97 22]
   [12 48]]
  ```

##  개선 방향

- `XGBoost` 기반 앙상블 기법 도입  
- 범주형 feature 고도화 (`Ticket`, `Cabin` 미활용)  
- `RandomizedSearchCV`를 통한 하이퍼파라미터 튜닝

##  프로젝트 회고

- **특성 공학의 효과**: `Title` 파생 변수로 성능 대폭 향상  
- **해석력 중심의 모델 선택 중요성** 체감  
- **ML 전 과정을 경험**하며 실무에 가까운 워크플로우 구성 가능  
- **도메인 기반 가설 설계와 검증**을 통한 분석 시야 확장
